# شرکت محاسبات عملیات داده ارزیابی نوین با مسئولیت محدود
## وب‌سایت جامع شرکتی و سامانه تحلیل داده‌های خطوط فرآوری مواد معدنی

> **شعار محوری:** «از داده‌های عملیاتی تا بینش هوشمند صنعتی»  
> **Brand Translation (Working):** Mohasebat Amaliat Dadeh Arzyabi Novin LLC  
> **معماری:** فرانت‌اند مستقل (Pure Client-Side + Build-time Prerendering) بدون وابستگی به بک‌اند و دیتابیس

---

## ۱. درباره پروژه و جایگاه برند

این پروژه یک وب‌سایت و پلتفرم صنعتی، مدرن و سازمانی در تقاطع **صنایع معدنی، فرآوری مواد معدنی، مهندسی داده و هوشمندسازی فرآیندهای صنعتی** است. این وب‌سایت نه صرفاً یک لندینگ‌پیج ساده، بلکه یک حضور دیجیتال کامل شرکتی با معماری محتوایی بهینه‌شده برای موتورهای جستجو (SEO)، پشتیبانی بومی از زبان فارسی و راست‌چین (RTL) و سیستم داده‌های محلی تایپ‌شده (Type-Safe) است.

### رعایت ضوابط دقت اطلاعات
تمامی متون بر پایه اطلاعات تاییدشده تدوین شده و از درج اطلاعات ساختگی (سال تاسیس، شماره ثبت جعلی، مشتریان خیالی، درصدهای اغراق‌آمیز یا ادعای پروتکل‌های اتوماسیون تاییدنشده) خودداری شده است. بخش‌های نیازمند تکمیل با پلیس‌هولدرهای مشخص در فایل‌های داده علامت‌گذاری شده‌اند.

## ۲. پشته فناوری (Technology Stack)

- **فریم‌ورک پایه:** React 18+ با Vite و TypeScript
- **استایل‌دهی:** Tailwind CSS با پالت رنگ اختصاصی صنعتی (سرمه‌ای `#101D2D`، آبی صنعتی `#245B8F`، سیان داده `#35B6C8`، مس معدنی `#B77A45`)
- **تایپوگرافی:** وزیرمتن (Vazirmatn) برای فارسی و Inter برای عبارات انگلیسی
- **انیمیشن‌ها:** Framer Motion (با رعایت استاندارد `prefers-reduced-motion`)
- **بصری‌سازی داده‌ها:** Recharts (نمودارهای تعاملی خط خوراک، توان مصرفی و عملکرد شیفت‌ها با برچسب مشخص DEMO DATA)
- **مسیریابی:** React Router DOM v6
- **آیکون‌ها:** Lucide React
- **اعتبارسنجی فرم‌ها:** React Hook Form + Zod
- **سئو و فراداده‌ها:** React Helmet Async + اسکریپت بیلد تایم Prerender جهت تولید صفحات HTML ایستا

## ۳. ساختار صفحات و مسیرها (Routes)

| :--- | :--- | :--- |
| `/` | `HomePage` | صفحه اصلی سازمانی با معرفی کامل، فرآیند داده، مزایا و پیش‌نمایش‌ها |
| `/about` | `AboutPage` | درباره شرکت، ماموریت، چشم‌انداز، ارزش‌ها و ساختار تیم |

| `/contact` | `ContactPage` | فرم استعلام و مشاوره با اعتبارسنجی Zod و خروجی Mailto سازمانی |

## ۴. مدیریت محتوا بدون بک‌اند (Local Content Management)

تمامی محتوا، عناوین و تنظیمات از طریق فایل‌های پوشه `src/data/` به سادگی و بدون نیاز به پنل ادمین یا دیتابیس قابل ویرایش هستند:

1. `src/data/company.ts`:
   - نام رسمی، شعار، ماموریت، چشم‌انداز، ارزش‌ها و اطلاعات ثبتی/تماس (شماره ثبت، شناسه ملی، تلفن، ایمیل).
2. `src/data/platform.ts`:
   - قابلیت‌های فعال و تحت ارزیابی سامانه، مراحل گردش کار، داده‌های نمایشی داشبورد و پرسش‌های متداول.
3. `src/data/services.ts`:
   - مشخصات کامل ۶ خدمت مهندسی داده (قابلیت افزودن خدمت جدید یا فعال/غیرفعال‌سازی).
4. `src/data/industries.ts`:
   - صنایع هدف، مدارهای فرآوری، متغیرهای داده‌ای و تصاویر صنعتی.
5. `src/data/projects.ts`:
   - پروژه‌ها و مطالعات موردی تاییدشده (پس از اخذ تاییدیه از کارفرما کافی است آبجکت جدید با `isVerified: true` اضافه شود).
6. `src/data/articles.ts`:
   - مقالات تخصصی دانشنامه با محتوای ساختاریافته HTML، تگ‌ها و فهرست سرفصل‌ها.
7. `src/data/seo.ts`:
   - خوشه‌های کلیدواژه‌های فارسی و انگلیسی، عناوین متادیتا و تنظیمات نقشه سایت.

## ۵. راهنمای افزودن مقاله جدید به دانشنامه

برای انتشار مقاله جدید، کافی است فایل `src/data/articles.ts` را باز کرده و یک رکورد جدید به آرایه `articlesData` اضافه کنید:

```typescript
{
  id: 'art-4',
  slug: 'new-article-slug',
  title: 'عنوان جذاب و تخصصی مقاله',
  summary: 'خلاصه دوخطی از موضوع و دستاوردهای مقاله',
  category: 'فرآوری مواد معدنی', // از میان دسته‌بندی‌های تعریف‌شده
  author: 'نام نویسنده یا گروه مطالعات داده نوین',
  publishedAt: '۱۴۰۳/۰۹/۱۰',
  readingTime: '۵ دقیقه',
  status: 'draft', // یا 'published'
  tags: ['کانی‌آرایی', 'بهینه‌سازی', 'داده صنعتی'],
  tableOfContents: [
    { id: 'sec-1', title: 'عنوان بخش اول' },
    { id: 'sec-2', title: 'عنوان بخش دوم' }
  ],
  contentHtml: `
    <section id="sec-1">
      <h2>عنوان بخش اول</h2>
      <p>متن تخصصی به زبان فارسی...</p>
    </section>
  `
}
```

## ۶. معماری سئو و پیش‌رندرینگ ایستا (SEO Prerendering)

برای غلبه بر محدودیت‌های SPA در موتورهای جستجو:
1. در زمان بیلد (`npm run build`)، اسکریپت `scripts/prerender.js` به صورت خودکار برای تمام ۲۲ مسیر اصلی پروژه، یک فایل `index.html` ایستا با تگ‌های متای اختصاصی، عنوان یکتا، پیوند کانونیکال (Canonical) و پیش‌نمایش Open Graph تولید می‌کند.
2. فایل‌های `public/sitemap.xml` و `public/robots.txt` برای خزنده‌های گوگل و بینگ پیکربندی شده‌اند.
3. ساختار داده‌های نشاندار (JSON-LD) برای سازمان (Organization)، خدمات (Service) و مقالات (Article) درون صفحات تعبیه شده‌اند.

## ۷. دستورات اجرا و استقرار (Commands)

```bash
# نصب وابستگی‌ها
npm install

# اجرای سرور توسعه محلی
npm run dev

# ساخت نسخه نهایی پروداکشن (تایپ‌چک + بیلد Vite + تولید پیش‌رندر ایستا برای ۲۲ مسیر)
npm run build

# پیش‌نمایش بیلد نهایی
npm run preview
```

### نحوه استقرار (Deploy)
خروجی پوشه `dist/` کاملاً ایستا و سبک است و می‌توان آن را روی:
- هاست‌های لینوکسی (Nginx / Apache / Cpanel / DirectAdmin)
- فضاهای ابری داخلی (آروان، پارس‌پک، چابکان و ...)
- پلتفرم‌های ابری بین‌المللی (Vercel, Netlify, Cloudflare Pages, GitHub Pages)
مستقر کرد.
